# The Bonzy Almanac

Every Project Zomboid (Build 42) recipe that has to be learned, and every way to unlock it: auto-learn skill levels, research, literature, and professions/traits.

Live: https://bonsai0t.github.io/bonzy-almanac/

Streams: https://www.twitch.tv/sogoodbonzy

## Languages

The flag button in the header switches the page between English and the 27 other languages Project Zomboid ships. Game names (items, recipes, skills, traits, occupations, crops) come from the game's own translation files; the rest of the page was machine-translated by Claude. Language packs live in `lang/<code>.json`.

## AI disclosure

Built with Claude (Anthropic). Claude wrote the parser that pulls the recipe data out of the game's `media/scripts/generated` files and wrote the page code, working from BonSAI0t's prompts and corrections. The data comes straight from the scripts, but the research rules (researching a recipe from its own output item, and the default research level) are inferred, so check in game before relying on them.
